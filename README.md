# DMS-LaP2019
This repository contains original DMS/P/O and tracer data (in .mat format) collected during La Perouse program in 2019 summer.

`LaP2019_uw_tsg.mat` is the continuous DMS/P/O concentrations collected by the underway OSCCAR system with mapped TSG data.

`LaP2019_peter_dmsop.mat` is the discrete DMS/P/O samples collected by a triple quadrupole mass spectrometer.

`LaP2019_peter_raw.mat` is the raw tracer data from the stable isotope tracer experiments to calculate reaction rate constants.
